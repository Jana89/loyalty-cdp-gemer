# Macta Flow Loyalty & CDP Demo

Vercel-ready Next.js prototype for a client-facing loyalty and CDP concept.

## What this prototype shows

- Loyalty as a practical cross-channel layer, not just points
- Store enrollment and missed-points correction workflows
- Customer 360 view combining store, online, refund, and messaging context
- CDP extension on top of loyalty for segmentation and operational triggers

## Stack

- Next.js (App Router)
- React
- Plain CSS for easy deployment and zero extra config

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

1. Push this folder to a GitHub repo
2. Import the repo into Vercel
3. Framework preset: Next.js
4. Root directory: repo root
5. Deploy

## Notes

This is a prototype/demo app, not a production integration.
